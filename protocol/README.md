# Protocol snapshot

`dsh-bridge-protocol.md` is a pinned public copy of the AgentPet DSH bridge
protocol v1. `dsh-bridge-v1.json` is its synthetic conformance fixture. Both are
checksum-pinned in `SHA256SUMS`; update them together with a protocol review.
The AgentPet Lite project remains the normative owner of the contract. No
AgentPet checkout is required to build or test this adapter.
